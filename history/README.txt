PTAR STEP-WENO OFFICIAL CONTINUATION v01
=======================================

Purpose
-------
This package continues the exact unfinished STEP-WENO branch recovered from
"NIS + Génération NVENC /4" without fabricating the missing PTAR corpus.

Files
-----
00_BASELINE_CHECKPOINT.txt
    Recovered official project checkpoint.

ptar_step_weno_reference.py
    Standard-library Python reference implementation of the STEP-WENO primitive.

ptar_step_weno_lite.hlsli
    HLSL helper intended for integration inside the already-existing EDGE v03
    directional path. It does not implement routing, texture access or an extra pass.

ptar_step_weno_arithmetic_mirror.cpp
    Small C++ arithmetic mirror used for native compile/run verification.

validate_step_weno.py
    Deterministic formal/property validation.

STEP_WENO_FORMAL_VALIDATION.txt
    Validation output generated by the test suite.

STEP_WENO_OFFICIAL_STATUS.txt
    Exact current decision gate and what remains empirically unproven.

Important
---------
This package does not contain nor depend on the previously generated synthetic
STEP-WENO benchmark. Those results remain excluded from the official PTAR lineage.

The HLSL file is an integration helper, not a standalone shader. It deliberately
takes epsilon, luminance values and EDGE confidence from the existing caller so
that missing project parameters are not guessed.
