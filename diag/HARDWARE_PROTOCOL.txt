PTAR GW16G QUALITYSAFE1 — HARDWARE PROTOCOL
============================================

Objective: validate CTRL+F8 live quality changes without altering the accepted GW16F NOLOCK30_1 presentation policy.

A. PRE-FLIGHT
1. Install with 01-INSTALL_GW16.bat.
2. 02-VERIFY_INSTALL.bat must report VERIFY=PASS.
3. Use the same Windows 8.1 / GTX 960M field setup and a scene already known to run correctly with GW16F.

B. PRIMARY /2-TIER CTRL+F8 GATE
1. Start with FG OFF for >=10 s.
2. CTRL+F6 once to enable FG.
3. Wait 3-5 s and confirm normal rendering.
4. CTRL+F8 once: show current profile only.
5. CTRL+F8 again while the notice remains visible: QUALITY (2) -> CONSERVATIVE (3).
6. Repeat if useful. While FG is ON, selection must remain within 2 <-> 3.
7. Play for >=20 s after the change.
8. Failure conditions: crash/black screen, FG presenter release/recreate, live 960x544 -> 640x368 ME resize, swapchain creation failure, separate-device preparation failure, plain F8 Status leakage, or plain F6 Manual Scaler leakage.
9. Leave FG ON and collect results immediately.

C. OPTIONAL /3-TIER GATE
1. CTRL+F6 OFF.
2. With FG OFF, use CTRL+F8 to select profile 0 or 1; full 0->1->2->3 selection is allowed only while FG is OFF.
3. CTRL+F6 ON.
4. While FG is ON, CTRL+F8 must remain within 0 <-> 1 and must not rebuild the ME ring/presenter.
5. Leave FG ON and collect results.

D. PERFORMANCE POLICY
GW16F NOLOCK30_1 is intentionally unchanged: target60 / Sync1 while FG is ON, with no automatic target30 / Sync2 clamp. This gate is about quality/hotkey safety, not re-tuning the frame-rate controller.

Authoritative evidence: runtime hotkey/presenter logs plus collected state. If a visible-frame measurement is also run, VBLANK3/PACINGVERIFIER3 remains authoritative for visible cadence.
