PTAR RC17 - DIAGREPAIR4 / HOTKEYFIX1 / INSTALLVERIFY2 STATIC VALIDATION
====================================================================

SCOPE
-----
Repairs only the existing visible-FPS diagnostic chain. The RC17 frame-generation runtime and production INI are unchanged.

ROOT CAUSE ADDRESSED
--------------------
The existing visible verifier waited for a global GetAsyncKeyState chord that required both VK_CONTROL and an F5 edge. On the current Inquisitor test this chord did not start the measurement. DIAGREPAIR4 removes the fragile CTRL gate from the existing verifier and elevates the existing 04 entry point before direct launch. F5 alone starts the same 20-second measurement; CTRL+F5 remains compatible.
