DIAGREPAIR3
-----------
04-ARM_VISIBLE_FRAME_VERIFIER.bat is the existing diagnostic entry point.
It self-relaunches under CMD /K, enables/confirms VBlankDiagnostics=1 with the existing Win32 INI helper, then executes the original visible verifier directly.
No PTAR_INSTALL_TEE_RAW.ps1, stdout pipe, output redirection, or START detachment is used for the verifier.
If the verifier or a later command exits immediately, CMD /K remains open.

INSTALLVERIFY1
--------------
01-INSTALL_FULLSTACK1.bat calls VERIFY_FULLSTACK1_INSTALL.bat /AUTO after core success.
Final installer PASS requires both core RC=0 and FULLSTACK verification RC=0.
VERIFY_FULLSTACK1_INSTALL.bat writes PTAR_VERIFY_LAST.log and repeats all [FAIL] lines at the end on failure.
The installed DLL SHA-256 check uses diag/PTAR_SHA256.ps1 with .NET SHA256 rather than parsing localized CertUtil prose.

CLEANUP / COLLECTION
--------------------
The safe uninstaller recognizes the new verify/status logs and exact legacy diagnostic outputs/backups.
05-COLLECT_RESULTS.bat copies the verify log and visible-verifier status when present.
