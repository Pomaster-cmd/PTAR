PTAR DISPLAY DELIVERY LAB - DWMPHASE1 - RC18 BASE
=================================================

OBJECTIF
--------
Localiser la phase de composition DWM ou les frames GENERATED de RC18 sont perdues.
Le runtime conserve exactement la politique RC18 PRESENTDELIVERY1: DISCARD, Present(1,0), aucun pre-WaitForVBlank.
Le diagnostic echantillonne seulement 1 frame sur 8 pour chaque type GENERATED/REAL.
Aucun Sleep, DwmFlush, waitable object ou changement de pacing n est ajoute.

CONTRAT WINDOWS 8.1
-------------------
DwmGetCompositionTimingInfo est resolu dynamiquement depuis dwmapi.dll.
Sous Windows 8.1, hwnd est obligatoirement NULL.
DWM_TIMING_INFO utilise la taille MSVC/Windows 292 octets (pack 4).

HOTKEYS DIAG
------------
CTRL+F4 : affiche le HUD DWM LAB et ecrit le snapshot DWMPHASE1 dans win81_nis.log.
CTRL+F5 : affiche le HUD VISIB TEST. Le visible verifier arme avant le jeu utilise le meme raccourci.
ESC : aucun effet sur ces diagnostics.

PROTOCOLE
---------
1. Installer ce LAB et exiger PASS GLOBAL du VERIFYFIX5.
2. Avant d ouvrir/revenir au jeu, lancer diag\04-ARM_VISIBLE_FRAME_VERIFIER.bat.
3. Lancer Inquisitor, meme scene de reference ~16 FPS natifs, profil CONSERVATIVE.
4. Noter le FPS FG OFF.
5. CTRL+F6 ON. Attendre 3-5 secondes. Noter le HUD interne.
6. CTRL+F5 une fois. Le HUD doit afficher VISIB TEST. Laisser 20 secondes.
7. Pendant que FG reste ON, CTRL+F4 une fois. Le HUD doit afficher DWM LAB.
8. Faire une capture du resume du visible verifier.
9. CTRL+F6 OFF une seule fois et laisser le jeu tourner au moins 60 secondes.
10. Quitter normalement puis lancer diag\05-COLLECT_RESULTS.bat.

NEUTRALITE DU LAB
-----------------
Si le HUD DISPLAY ou le FPS source chute de plus de 5% par rapport a RC18 sur la meme scene, le diagnostic est considere perturbateur et ses phases ne doivent pas guider une correction de production.

SNAPSHOT DWMPHASE1
------------------
REFRESH US : periode DWM observee en microsecondes.
GS0..GS7 : phase de DEBUT du Present GENERATED, 8 tranches du cycle VBlank.
GE0..GE7 : phase de FIN du Present GENERATED.
RS0..RS7 : phase de DEBUT du Present REAL.
RE0..RE7 : phase de FIN du Present REAL.
CP0..CP7 : phase qpcCompose DWM.
DWM DISPLAYED/DROPPED/LATE DELTA : compteurs DWM globaux entre premier et dernier echantillon, contexte uniquement.

Chaque bucket couvre 1/8 de la periode de rafraichissement. A 60 Hz, environ 2,08 ms par bucket.
Le critere decisif est la separation de phase G/R confrontee au visible verifier externe.
