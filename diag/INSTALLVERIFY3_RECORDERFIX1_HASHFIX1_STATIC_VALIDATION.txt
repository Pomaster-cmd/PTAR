PTAR RC17 - INSTALLVERIFY3 / RECORDERFIX1 / HASHFIX1
Date: 2026-08-30

FIELD FAILURE ADDRESSED
- Fresh install could finish the core successfully but FULLSTACK verification reported VideoRecordProfile=1 while production contract requires profile 3.
- Cause: PTAR_CORE_INSTALL.bat initialized KEEP_VIDEO_PROFILE to 1 and preserved 1/2/3 from a target INI; the launcher baseline profile 3 was not authoritative inside the core.
- Fix: production recorder profile is forced to 3 during the core merge.

SHA-256 VERIFIER FAILURE ADDRESSED
- INSTALLVERIFY2 invoked PTAR_SHA256.ps1 through a nested FOR /F command and suppressed stderr; on the Windows 8.1 field machine both DLL and visible-verifier hashes returned empty.
- Fix: PTAR_SHA256.ps1 uses PowerShell-4-compatible output, callers capture it through a temp file, and native CertUtil is an independent fallback.
- CertUtil parsing ignores localized header/footer text and consumes the hash data line only.

NON-REGRESSION CONTRACT
- Runtime DLL unchanged.
- Visible verifier HOTKEYFIX1 unchanged.
- FGQUALITY3 / CONSERVATIVE unchanged.
- SHARELEGACY3 / RESIZEGUARD1 / FGREAL30 / cadence unchanged.
- Diagnostic entry remains diag\04-ARM_VISIBLE_FRAME_VERIFIER.bat; no parallel diagnostic routine added.
