GW15 DESIGN
-----------
- Runtime is byte-identical to hardware-tested GW13 all-frame SyncInterval=2 runtime:
  2fbd2343803af619621282fface48c469092c16d5139ec0ce52b35affb83d29d
- Only package policy changes: FrameGenerationTargetFPS 60 -> 30.
- Existing FGREAL governor contract is REAL target = FrameGenerationTargetFPS / 2,
  therefore GW15 REAL target = 15 FPS.
- On a fixed 60 Hz display, Sync2 G + Sync2 R consumes exactly 4 VBlanks/pair = 15 pairs/s.
- The observed GW13 field source was 15.387 pairs/s, 2.58% above that service capacity.
  This positive queue slope is consistent with the pressure/drop behavior observed in GW13.
- GW15 removes that modelled service-rate mismatch without adding new runtime code.
