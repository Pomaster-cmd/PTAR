INSTALLFIX3 - WINDOWS 8.1 CMD PATH-PARSER VALIDATION
--------------------------------------------------
Observed target log reached STEP 05/08 PASS and then aborted with RC=255:
  \Steam\steamapps\common\Warhammer etait inattendu.

Root cause isolated to :QUARANTINE. The previous body expanded %~dp1 inside
a parenthesized FOR/IF block. The target root is under Program Files (x86),
and CALL causes a second CMD parse in which the path parenthesis can terminate
block syntax.

INSTALLFIX3 remains installer-only and changes two path-safety points:
  ROOT_DLL and TARGET_DLL are canonicalized before the bounded stale-copy comparison,
  preventing the same physical target from being misclassified due to duplicate \\;
  :QUARANTINE then uses the safe argument handling below.
  OLD=%~1 is captured on a standalone line;
  OLD_DIR is derived using delayed expansion;
  all block-time path references use !OLD! / !OLD_DIR!;
  quarantine remains a rename/move, never a delete or overwrite.
