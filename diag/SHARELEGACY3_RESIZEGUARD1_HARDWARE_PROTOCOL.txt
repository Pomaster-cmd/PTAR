PTAR RC12 — SHARELEGACY3 + RESIZEGUARD1 HARDWARE PROTOCOL

Target field machine for this run: Windows 8.1 x64 + GTX 960M.
Game: Warhammer 40,000: Inquisitor - Martyr / Warhammer.exe.

Purpose:
Validate that legacy shared-resource FG can remain alive while Inquisitor repeatedly asks the game swapchain to ResizeBuffers to native output size.

Procedure:
1. Close the game completely.
2. Install RC12 with 01-INSTALL_FULLSTACK1.bat.
3. Run VERIFY_FULLSTACK1_INSTALL.bat and require PASS.
4. Use 1280x720 game render -> 1920x1080 PTAR output.
5. Keep the game's V-Sync enabled for this diagnostic. PTAR Auto-VSync is still not implemented.
6. Before FG, verify normal uncapped behavior (no persistent 30 FPS governor while FG is OFF).
7. Press CTRL+F6 once.
8. If FG remains alive, play 15-20 seconds only.
9. Press F8 once.
10. Press CTRL+F6 once to disable FG, if still active.
11. Do NOT test CTRL+F9 recorder.
12. Exit cleanly if possible and run diag\05-COLLECT_RESULTS.bat.

Expected RC12 behavior:
- Keyed-primary sessions: RESIZEGUARD1 inactive.
- Legacy fallback before scheduler start: RESIZEGUARD1 inactive.
- Legacy fallback with scheduler running: game ResizeBuffers is rejected without FG teardown/rebuild.
- FG OFF: original ResizeBuffers path restored immediately.
- Governor 30 FPS remains GATE1-only and must disappear when FG is not running.

If the game crashes again, do not make a second activation attempt in the same run. Collect the result immediately.
