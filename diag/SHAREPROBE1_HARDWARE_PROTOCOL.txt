PTAR RC9 — SHAREPROBE1 HARDWARE PROTOCOL
=========================================
Purpose: identify which shared Texture2D creation modes the actual Inquisitor D3D11 game device / Windows 8.1 NVIDIA driver accepts after the inherited SHARED_KEYEDMUTEX descriptor returns E_INVALIDARG.

Safety / scope:
- Probe executes ONLY after FGCreateSharedTransport has already failed with E_INVALIDARG (0x80070057).
- It does not enable FG.
- It does not change PTAR-NG, INPUTMAP2, presenter, GATE1, governor timing, NVENC, mailbox, VBlank, recorder, hotkeys or INI.
- Seven temporary 1280x720-format textures are attempted on the same game device.
- Any successful temporary texture is immediately IUnknown::Release'd.
- The original FG failure/cleanup path is then resumed.

P1FG7N LAST STATUS encoding for E_INVALIDARG probe runs:
  0xE3000000 | MASK

MASK bits:
  0x01 = ordinary texture, no sharing, Bind SRV|RTV (0x28)
  0x02 = D3D11_RESOURCE_MISC_SHARED (0x2), Bind SRV|RTV
  0x04 = inherited D3D11_RESOURCE_MISC_SHARED_KEYEDMUTEX (0x100), Bind SRV|RTV
  0x08 = SHARED_KEYEDMUTEX, Bind SRV only (0x08)
  0x10 = SHARED_KEYEDMUTEX, Bind RTV only (0x20)
  0x20 = D3D11_RESOURCE_MISC_SHARED_NTHANDLE (0x800), Bind SRV|RTV
  0x40 = SHARED_NTHANDLE | SHARED_KEYEDMUTEX (0x900), Bind SRV|RTV

Examples:
  0xE3000001 = only ordinary non-shared texture succeeded.
  0xE3000003 = ordinary + legacy SHARED succeeded.
  0xE3000041 = ordinary + NT-HANDLE+KEYED succeeded.
  0xE300007F = every probe succeeded.

If the original failure changes to a non-E_INVALIDARG HRESULT, RC9 preserves that raw HRESULT instead of running the probe matrix.

Test:
1. 1280x720.
2. FG OFF normal framerate.
3. CTRL+F6 once.
4. Wait 2-3 seconds.
5. F8 once.
6. Quit normally.
7. diag\05-COLLECT_RESULTS.bat.
8. Return the result ZIP.
